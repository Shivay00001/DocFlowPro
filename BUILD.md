# DocFlow Pro v2.0 - AI Data Factory Edition

## Quick Start

### Run from Source

```bash
# Install dependencies
pip install -r requirements.txt

# Run application
python main.py
```

### Build Executable

```bash
# Install build tools
pip install pyinstaller

# Build
pyinstaller docflowpro.spec --clean

# Run
dist\DocFlowPro\DocFlowPro.exe
```
